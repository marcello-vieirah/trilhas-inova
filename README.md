# Trilhas Inova - Desafios/Exercícios

Este é um repositório dedicado aos desafios de programação/exercícios práticos desenvolvidos durante o programa **Trilhas**, associado ao **Inova Maranhão**.

Os desafios estão organizados por pastas/níveis para refletir a progressão do aprendizado.

## Tecnologias

As linguagens e ferramentas podem variar conforme o desafio. Atualmente, o foco principal é:
*   Python
